# Stage 1: Check the computer is ready

## Goal
Make sure the programs work, switch off training on their conversations, open their notebook in Obsidian with its add-ons switched on (three ship inside the notebook: Dataview, Templater and Periodic Notes), switch on the quick way to search it, and confirm the time zone. The user should feel this is easy and safe.

## Steps
1. **Greet.** If `name` in `playbook/state/profile.json` is empty (a pack made for anybody), first say hello without a name and ask in a question box: en-GB "What would you like me to call you?" es-MX "¿Cómo te gusta que te diga?" Options: **My first name, I'll type it (Recommended)** / **tell me more** (es-MX **Mi nombre, lo escribo (Recomendado)** / **cuéntame más**). Write the name they give into `name` in `profile.json` with the file-writing tool, keeping every other value. Test mode: take the name from the `## Stage 1` answers in `playbook/test-answers.md`. Greet them by first name (from `playbook/state/profile.json`) in their language. One line on what is about to happen, and nothing technical:
   en-GB: "Hello <name>. I'm Claude, the helper Kas set up for you. First I'll check everything is ready. Then we'll make your notebook together. It takes about 90 minutes. You can stop any time: just type pause."
   es-MX: "Hola <name>. Soy Claude, el ayudante que Kas te preparó. Primero reviso que todo esté listo. Luego armamos tu cuaderno. Toma como 90 minutos. Puedes parar cuando quieras: solo escribe pausa."

2. **Check the programs quietly.** Do not narrate the checks. Run each one:
   - `git --version` (any version number = fine).
   - Obsidian: check the file `%LOCALAPPDATA%\Programs\Obsidian\Obsidian.exe` exists (run exactly `Test-Path "$env:LOCALAPPDATA\Programs\Obsidian\Obsidian.exe"` with the PowerShell tool; this exact command is pre-allowed, so never reword it or list that folder another way).
   - yt-dlp: run `where.exe yt-dlp` (it must print a path; also accept `%LOCALAPPDATA%\Microsoft\WinGet\Links\yt-dlp.exe` existing), then run `powershell -NoProfile -ExecutionPolicy Bypass -File playbook/tools/get-subs.ps1 -Url https://youtu.be/dQw4w9WgXcQ -ValidateOnly` (exit code 0 = fine). Never run `yt-dlp` itself; it is blocked on purpose.
   - Claude app: you are running inside it, so it is fine.
   - Node.js (a small engine the planning tool runs on; never name it to the user): run `where.exe node`. Also accept `node.exe` found with the Glob tool in `C:/Program Files/nodejs`.
   If something is missing, tell them only: en-GB "One piece didn't install. I'll fix it now." es-MX "Una pieza no se instaló. La arreglo ahorita." Then run `winget install --id <id> --exact --silent --accept-package-agreements --accept-source-agreements` with the matching id: `Git.Git`, `Obsidian.Obsidian`, `yt-dlp.yt-dlp`, `OpenJS.NodeJS.LTS`. Check again. If it still fails after a second try, follow the "fails twice" rule in `PLAYBOOK.md`.
   - The planning tool (used later by the `big-plan` helper): read `.claude/get-shit-done/VERSION` with the Read tool. If it is there, fine. If it is missing, run exactly `powershell -NoProfile -ExecutionPolicy Bypass -File playbook/tools/install-planner.ps1` (this exact command is pre-allowed; it only adds the tool's own files and never changes the safety settings). If it still is not there after a second try, do not stop and do not tell the user: write `planner: missing` to `playbook/state/planner.md` and carry on. The helper has a plain way that works without it, and Kas can add it later. When it is there, write `planner: ready`.
   Test mode: never install anything on the rehearsal computer. If a program check fails, log `SKIPPED-TEST 1.2 <program> not installed` in `playbook/state/test-log.md` and count that check as passed. Never run the planning tool installer: write `planner: skipped-test` and log `SKIPPED-TEST 1.2 planning tool`.

3. **Training off.** Show a question box:
   en-GB: "Let's keep your chats private. In this Claude window, look at the bottom-left corner. Click your name, or the small circle with your first letter. Click Settings, then Privacy. Find the switch called 'Help improve Claude'. Click it so it goes grey. Grey means off. Did that work?" Options: **Done, it's off (Recommended)** / **I can't find it** / **Explain more**.
   es-MX: "Vamos a cuidar que tus pláticas sean privadas. En esta ventana de Claude, mira la esquina de abajo a la izquierda. Dale clic a tu nombre o al circulito con tu inicial. Dale clic en Configuración (o Settings) y luego en Privacidad (o Privacy). Busca el interruptor que dice 'Help improve Claude' (o 'Ayudar a mejorar Claude'). Dale clic para que se ponga gris. Gris quiere decir apagado. ¿Funcionó?" Options: **Listo, ya está apagado (Recomendado)** / **No lo encuentro** / **Explícame más**.
   - "I can't find it" or "Explain more": say it again in even smaller steps, one place at a time (the bottom-left corner of the Claude window; the little circle with their first letter; the word Settings in the list; then Privacy on the left), then ask the same box again. Do not move on until they pick Done.
   - Test mode: log `SKIPPED-TEST 1.3 training switch` in `playbook/state/test-log.md` and use the next answer.

4. **Open the notebook in Obsidian.** First say what it is, in one line: en-GB "Now I'll open your notebook. It lives in a program called Obsidian. Think of it as a paper notebook on the computer: folders down the left, your notes on the right." es-MX "Ahora abro tu cuaderno. Vive en un programa que se llama Obsidian. Es como un cuaderno de papel, pero en la computadora: las carpetas a la izquierda y tus notas a la derecha."
   Then open it with PowerShell: `Start-Process "obsidian://open?path=<vault path, URL-encoded>"` (the vault path is the folder you are working in). If Obsidian opens without the notebook, walk them through opening their notebook folder, one click per question box: Obsidian's button for this is labelled "Open folder as vault" (quote that label exactly as the app shows it, but always call it "your notebook folder" yourself), then they pick the folder.
   The notebook comes with three add-ons already inside it: Dataview, Templater and Periodic Notes. Obsidian keeps add-ons switched off until a person says yes by hand, on every new computer. So the first box covers the question Obsidian may ask as soon as the notebook opens. Walk them through it one click at a time, each with a question box (options en-GB: **Done (Recommended)** / **Stuck** / **Explain more**; es-MX: **Listo (Recomendado)** / **Me atoré** / **Explícame más**):
   a. en-GB: "Obsidian may show a box asking if you trust the author of this notebook. Kas made it for you, so it's safe: click 'Trust author and enable plugins'. No box? That's fine too. Then look at the bottom-left corner of Obsidian and click the little gear wheel. That opens Settings." es-MX: "Puede que Obsidian te muestre un aviso preguntando si confías en quien hizo este cuaderno. Lo hizo Kas para ti, así que es seguro: dale clic en 'Trust author and enable plugins'. ¿No salió ningún aviso? También está bien. Luego mira la esquina de abajo a la izquierda de Obsidian y dale clic al engrane chiquito. Así se abre la Configuración."
   b. en-GB: "On the left of that window, click 'Community plugins'. Plugins are small add-ons for Obsidian." es-MX: "A la izquierda de esa ventana, dale clic en 'Community plugins'. Los plugins son extras pequeños para Obsidian."
   c. en-GB: "If you see a button that says 'Turn on community plugins', click it. It lets the add-ons Kas put in your notebook work. If a box asks whether you trust the author, click 'Trust author and enable plugins'. Now look lower down for three names: 'Dataview', 'Templater' and 'Periodic Notes'. Those are the add-ons Kas put in for you. Each switch should be on (coloured, not grey). If one is grey, click it once." es-MX: "Si ves un botón que dice 'Turn on community plugins', dale clic. Así funcionan los extras que Kas puso en tu cuaderno. Si sale un aviso preguntando si confías en quien lo hizo, dale clic en 'Trust author and enable plugins'. Ahora busca más abajo tres nombres: 'Dataview', 'Templater' y 'Periodic Notes'. Son los extras que Kas te puso. Cada interruptor debe estar prendido (de color, no gris). Si alguno está gris, dale un clic."
   d. en-GB: "Close the Settings window with the X in the top-right corner." es-MX: "Cierra la ventana de Configuración con la X de la esquina de arriba a la derecha."
   After d, say in short lines what the three add-ons do: en-GB "Kas put three small add-ons in your notebook. Dataview makes lists for you by itself, like your week and your goals on one page. Templater gives each new note a ready-made shape, so you never start with a blank page. Periodic Notes makes today's note and this week's note in the right folder. You never need to touch them." es-MX "Kas puso tres extras pequeños en tu cuaderno. Dataview hace listas solito, como tu semana y tus metas en una sola página. Templater le da a cada nota nueva una forma ya hecha, para que nunca empieces con la hoja en blanco. Periodic Notes hace la nota de hoy y la de esta semana en su carpeta. No tienes que moverles nada."
   On **Stuck**: ask what they see on screen (box with 3 likely answers, for example "a box asking about trust" / "no button, only a list" / "something else") and guide from there. If one of the three names is not in the list at all, say kindly it can be fixed later, and carry on; stage 4 checks it again. Test mode: log `SKIPPED-TEST 1.4 Obsidian add-ons` and use the next answer.

5. **The quick way to search the notebook.** Read `playbook/obsidian-tool.md` and follow its "Switching it on" part now, one click per question box. It is one switch and one button inside Obsidian; they can leave it for another day and nothing breaks.

6. **Time zone.** Read the time zone from the language profile ("Dates and time"), and check the computer's with `Get-TimeZone`. Show a question box: en-GB "What time is it where you are right now? Then your morning check-in comes at the right time." es-MX "¿Qué hora es donde estás ahorita? Así tu plática de buenos días llega a la hora correcta." Options: the current time in the profile's zone, shown as a clock time (Recommended); the current time in the computer's zone, if different; **Something else** (es-MX: **Otra hora**). Write the confirmed zone (IANA name, for example `Europe/London` or `America/Mexico_City`) to `playbook/state/timezone.md` as `timezone: <zone>`.

7. **Talking instead of typing.** Tell them once, in one sentence: en-GB "If you'd rather talk than type, press the Windows key and H together, then speak; press them again to stop." es-MX "Si prefieres hablar en vez de escribir, presiona la tecla de Windows y la H al mismo tiempo y habla; presiónalas otra vez para parar." Do not repeat it in setup until stage 3, which reminds them once (as the access profile says).

8. **Finish.** When everything under "Done when" is true, create `playbook/state/stage-1.done` (one line: the date and time), set `current_stage: 2` and `updated: <now, ISO 8601>` in `playbook/progress.md`, and move on to stage 2 in the same sitting unless they typed pause.

## Done when
- `git --version` answers, Obsidian.exe exists, and `where.exe yt-dlp` finds it with the get-subs check returning 0 (in test mode, a missing program logged as SKIPPED-TEST counts as found).
- The user picked "Done" for training off (or test mode logged it as SKIPPED-TEST).
- Obsidian add-ons are switched on with Dataview, Templater and Periodic Notes in the list (or logged as SKIPPED-TEST) and `playbook/state/timezone.md` exists.
- `playbook/state/planner.md` says `planner: ready`, `missing` or `skipped-test`, and `playbook/state/obsidian-tool.md` says `cli: on`, `pending`, `skipped` or `skipped-test`.
- `playbook/state/stage-1.done` exists.
