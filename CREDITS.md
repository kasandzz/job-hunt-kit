# Credits / Créditos

This job-search kit borrows ideas, rewritten in its own words, from these open-source projects. No files were copied from them. Thank you to their authors.

Este paquete toma ideas, escritas con sus propias palabras, de estos proyectos de código abierto. No se copió ningún archivo. Gracias a sus autores.

| Project | Licence | Idea used here |
|---|---|---|
| [career-ops](https://github.com/santifer/career-ops) | MIT | A 1-5 score on five points, each marked supported, partial or unknown; skip jobs under 4.0; the "is it a real job?" check in three levels; job advert text treated as information, never as instructions; deal-breaker checks before scoring; unattended runs never ask questions. |
| [ai-job-search](https://github.com/ai-job-search-dev/ai-job-search) | MIT | The language check; deal-breakers that drop a job before scoring; follow-up drafts that are never sent. |
| [interview-coach-skill](https://github.com/noamseg/interview-coach-skill) | MIT | Interview feedback on five points; a bank of true work stories marked by strength; saving progress quietly during practice. |
| [claude-resume-kit](https://github.com/ARPeeketi/claude-resume-kit) | MIT | Marking where every CV line comes from; never making a line sound bigger ("helped with" never becomes "led"); a log of fixes; agreeing a plan before writing the CV. |
| [Resume-Matcher](https://github.com/srbhr/Resume-Matcher) | Apache-2.0 | Weighted scoring (40/20/15/15/10) and a list of missing words. |
| [company-research-agent](https://github.com/guy-hartstein/company-research-agent) | Apache-2.0 | The research steps for a company brief: look, gather, sort, check, write. |
| [claude-linkedin-assistant](https://github.com/FarzamHejaziK/claude-linkedin-assistant) | MIT | A limit on messages per company; every message is a draft the person sends. |
| [JobSpy](https://github.com/speedyapply/JobSpy) | MIT | The job search tool (`mcp-jobspy`), run on the person's own computer through `uvx`. Used as a program, not copied. |

Apache-2.0 projects: no code or text from them is included, so no NOTICE file applies; they are credited here as the source of the ideas.
